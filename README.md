# نوادر — موقع المانجا العربي

موقع كامل لقراءة المانجا والمانهوا والمانها مع لوحة تحكم إدارية، تعليقات،
تقييمات، قوائم قراءة، منتدى، رسائل خاصة، وضع ليلي وأكثر.

---

## التشغيل بأمر واحد (الأسهل)

### على لينكس / ماك:
```
bash run.sh
```

### على ويندوز:
```
run.bat
```

السكريبت يقوم تلقائياً بـ:
1. إنشاء بيئة بايثون افتراضية في `.venv`
2. تثبيت كل المتطلبات
3. تجهيز قاعدة البيانات
4. إنشاء حساب الإدارة
5. تشغيل الخادم على المنفذ 8000 (أو أي منفذ تختاره عبر `PORT=...`)

عند الانتهاء سيظهر لك في الطرفية:
```
الموقع       : http://127.0.0.1:8000/
لوحة الإدارة : http://127.0.0.1:8000/admin/
```

> لاستخدام منفذ مختلف:
> `PORT=9000 bash run.sh` (لينكس/ماك) أو
> `set PORT=9000 && run.bat` (ويندوز)

## التشغيل اليدوي (إن أردت)

```
python -m venv .venv
source .venv/bin/activate            # لينكس/ماك
.venv\Scripts\activate               # ويندوز

python -m pip install -r requirements.txt
python manage.py migrate
python manage.py seed_admin
python manage.py runserver 0.0.0.0:8000
```

> إذا ظهر خطأ `externally-managed-environment` فهذا لأن نظامك يمنع التثبيت
> العام لـ pip — استخدم بيئة افتراضية كما هو موضح أعلاه (السكريبت يفعل هذا تلقائياً)،
> أو أضف الخيار `--break-system-packages` على مسؤوليتك.

> إذا ظهر `That port is already in use` فاختر منفذاً آخر مثل
> `python manage.py runserver 0.0.0.0:8001`.

## الميزات

- **الواجهة الرئيسية**: الأكثر قراءة، أحدث الإضافات، تصنيفات النوع (مانجا/مانهوا/مانها)، آخر مشاهداتك.
- **بحث فوري** مع اقتراحات تلقائية ودعم للكلمات المفتاحية التي يضيفها الإداري.
- **صفحة تصفح** المكتبة مع فلاتر (نوع، تصنيف، ترتيب: الأحدث/الأكثر قراءة/الأعلى تقييماً/الاسم).
- **تفاصيل المانجا**: غلاف، قصة، تصنيفات، تقييم بالنجوم، قائمة فصول، شارة "جديد" للفصول خلال آخر 3 أيام، علامة مقروء.
- **قارئ فصول** بـ3 أوضاع (عمودي/ويب تون/أفقي) + دمج الصفحات + تنقّل سابق/تالٍ.
- **تحميل الفصل** كاملاً كملف مضغوط بترقيم الصفحات (مثل: `مانجا الهلاك، الفصل 1.zip`).
- **نظام تعليقات** على المانجا والفصول مع: ردود، إعجاب/عدم إعجاب، خيار حرق (سبويلر).
- **قوائم قراءة شخصية**: أرغب بمشاهدتها / لاحقاً / حالياً / تم.
- **ملف شخصي** قابل للتعديل: صورة، اسم ظاهر، نبذة، تفضيلات القارئ.
- **منتدى** نقاشات + **رسائل خاصة** بين المستخدمين + **نظام دعم فني**.
- **وضع ليلي/نهاري** قابل للتبديل ويُحفظ تلقائياً.
- **لوحة إدارة Django** كاملة بالعربية لإدارة المانجا والفصول والتصنيفات والتعليقات والمستخدمين والكلمات المفتاحية والحظر (حظر حساب أو جهاز).
- **تصميم متجاوب** مع شاشات الهاتف واللابتوب والتابلت.

## التخزين والإعدادات

- الصور تُحفظ محلياً داخل مجلد `media/`.
- قاعدة البيانات الافتراضية SQLite (`db.sqlite3`) في جذر المشروع.
- يمكن تخصيص مفتاح الأمان والمضيفين عبر ملف `.env`:
  ```
  SECRET_KEY=your-secret
  DEBUG=true
  ALLOWED_HOSTS=*
  ```

---

## النشر على استضافة خاصة

- استخدم خادم إنتاج مثل **Gunicorn**:
  ```
  gunicorn --bind=0.0.0.0:8000 nawadir.wsgi:application
  ```
- ضع `DEBUG=false` و `ALLOWED_HOSTS=yourdomain.com` في `.env`.
- اخدم ملفات `media/` و `static/` عبر nginx أو خدمة مماثلة.
