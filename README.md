# نوادر - موقع مانجا عربي

## التشغيل السريع

1) انسخ ملف الإعدادات:

```
cp .env.example .env
```

2) ثبّت المتطلبات:

```
python -m pip install -r requirements.txt
```

3) نفّذ الترحيلات وأنشئ حساب الإدارة الموحد:

```
python manage.py migrate
python manage.py seed_admin
```

4) شغّل الخادم المحلي:

```
python manage.py runserver
```

الروابط:
- الموقع: http://127.0.0.1:8000/
- لوحة الإدارة: http://127.0.0.1:8000/admin/

بيانات الدخول للإدارة:
- اسم المستخدم: **345789900Dd**
- كلمة المرور: **345789900Dd**

## ملاحظات
- يتم تخزين الصور محلياً داخل مجلد `media/`.
- يمكنك إدارة المانجا والفصول والتصنيفات والتعليقات من لوحة الإدارة.
- البحث الفوري يدعم العناوين والكلمات المفتاحية التي تضيفها في لوحة الإدارة.
