# نوادر — موقع المانجا العربي

موقع كامل لقراءة المانجا والمانهوا والمانها مع لوحة تحكم إدارية، تعليقات، تقييمات،
قوائم قراءة، منتدى، رسائل خاصة، وضع ليلي، وأكثر.

## التشغيل السريع

1) ثبّت المتطلبات:
```
python -m pip install -r requirements.txt
```

2) نفّذ الترحيلات وأنشئ حساب الإدارة:
```
python manage.py migrate
python manage.py seed_admin
```

3) شغّل الخادم:
```
python manage.py runserver 0.0.0.0:5000
```

الروابط:
- الموقع: http://127.0.0.1:5000/
- لوحة الإدارة: http://127.0.0.1:5000/admin/

بيانات دخول الإدارة:
- اسم المستخدم: **345789900Dd**
- كلمة المرور: **345789900Dd**

## الميزات
- صفحة رئيسية تعرض الأكثر قراءة، أحدث الإضافات، وتصنيفات النوع (مانجا/مانهوا/مانها).
- بحث فوري مع اقتراحات تلقائية ودعم للكلمات المفتاحية.
- صفحة تصفح المكتبة مع فلترة بالنوع والتصنيف والترتيب.
- تفاصيل المانجا: غلاف، قصة، تصنيفات، تقييم، تعليقات، قائمة فصول، شارة "جديد" للفصول الحديثة.
- قارئ فصول بثلاثة أوضاع (عمودي/ويب تون/أفقي) مع دمج الصفحات وتنقّل سابق/تالٍ.
- تحميل الفصل كاملاً كملف مضغوط بترقيم الصفحات.
- نظام تعليقات على المانجا والفصول مع رد، إعجاب/عدم إعجاب، خيار حرق (سبويلر).
- قوائم قراءة شخصية (أرغب/لاحقاً/حالياً/تم).
- ملف شخصي مع صورة، اسم ظاهر، نبذة، وتفضيلات القارئ.
- منتدى نقاشات، رسائل خاصة، دعم فني.
- وضع ليلي/نهاري قابل للتبديل.
- لوحة إدارة Django كاملة لإدارة المانجا والفصول والتصنيفات والتعليقات والمستخدمين والكلمات المفتاحية والحظر.

## ملاحظات
- الصور تُحفظ محلياً في مجلد `media/`.
- قاعدة البيانات الافتراضية SQLite (`db.sqlite3`).
- يمكن تعديل الإعدادات الحساسة عبر ملف `.env`.
